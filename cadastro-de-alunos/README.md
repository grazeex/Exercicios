# Aplicativo de cadastro de uma escola

## Fase inicial - cadastro de alunos

Faça um algoritmo para cadastrar alguns alunos por meio de uma estrutura de repetição, ou uma função de cadastro.

Receber os dados do aluno:

- Nome
- Sexo
- Endereço
- Cidade
- UF
- Pai
- Mãe
- Fone
- CEP
- RG
- Data de nascimento

Armazenar em uma variável dicionário.
